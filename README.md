For this project, we used comprehensive data on the performance of Portuguese students in math and Portuguese, which also included a number of 
characteristics about the students, such as their study time, whether or not they participated in outside activities, etc.

Our analysis attempted to address which features could reliably correlated to certain end of year grade outcomes. 

This analysis can be helpful for people working in education or policy who are considering what interventions to put in place to support students. 

To complete our analysis, we primarily used Python and PANDAS to load and display our dataset and sklearn packages to complete the various supervised and unsupervised learning models. We also used Tableau to create visuals of our project.

EDA → unsupervised → supervised modeling → dashboard
* We used the EDA process to get a better sense of what data was available to use, and to transform the data in ways that made future modeling easier
* We used the clustering framework within the unsupervised learning model to determine if the model could detect differences within two groups with the same features
* We used logistic and linear supervised learning models to see if the features we selected could reliably determine the correct end of year grade or end of year grade level
* We used Tableau to create dashboards to display our visualizations

Some key findings were many of the "lifestyle" features we used within our model did not correlate well to the end of year grade.
Previous academic performance, such as grades in previous grading periods, and whether or not the student had failed before, did a much better job of predicting the correct outcome.
